ช่วยเขียนความต้องการของผมช่วยเขียนเป็น Role Skill ให้หน่อย
เกี่ยวกับการเขียน Nextjs html

- การเขียน html format แบบที่ผิด
```
<button 
    type="button" 
    className="btn 
    btn-sm"
>
    New Project
</button>
```
แบบที่ถูก
```
<button type="button" className="btn btn-sm">
    New Project
</button>
```
- การใช้งาน libary ui จะต้องใช้งาน daisyui กับ tailwindcss เท่านั้น
- การเขียนด้วย AI ถ้าผมไม่ได้บอกให้คุณแต่งสีอะไรคุณจะต้องใช้งาน components default class หรือ Style ของ daisyui เท่านั้น
- โครงสร้างหน้าเว็บหนึง page จะเป็นลักษณะแบบนี้ เป็น format มาตฐานของ Project ทุก Project ของผม
```
./layout.tsx
./components
./components/footer.tsx
./components/navbar.tsx
./components/content.tsx
./components/sidebar.tsx
./dashboard/page.tsx
./projects/page.tsx
./users/page.tsx
./setting/page.tsx
./page.tsx
```
- ห้ามแก้ไขไฟล์อื่นที่ผมไม่ได้อนุญาติ
- จะต้องมีการเขียน comment ด้วย เป็นภาษา EN ห้ามมีอักษรพิเศษ
การเขียน comment ที่ผิด
```
// ============ Comment ============
```
การเขียน comment ที่ถูก
```
// Comment
```
- tailwindcss จะต้องใช้งาน responsive models sm, md, lg, xl, 2xl อย่างละเอียดมาก
- การใช้งาน Components จะต้องใช้งาน samll ที่สุดทั้งหมดเลยผมต้องการความกระชับและเรียบง่าย

ถ้าผมเขียนวนไปวนมาช่วยเรียกคำให้ใหม่ให้หน่อยแล้วก็เขียน Role ให้ละเอียดและต้องให้ AI  ปฏิบัติตามกฏอย่างเคร่งครัด
เขียนเป็นภาษา EN
พร้อมบอกด้วยจะต้องตั้งชื่อไฟล์ skill ว่าอะไร
